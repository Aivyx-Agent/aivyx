# Aivyx Docs — Archive

Frozen, point-in-time documentation. Nothing here is edited after it
lands — these are historical artifacts preserved for provenance. For
current project state, start at [`../../README.md`](../../README.md);
for the living docs index, see [`../README.md`](../README.md).

## Contents

- [`phases/`](phases/) — the **phase journals** `PHASE_0.md` through
  `PHASE_185.md`: the working document for each numbered phase, frozen
  at phase exit. The canonical phase index (status + exit commit per
  phase) is the *Phase status* table in [`../README.md`](../README.md).
- [`walkthrough.md`](walkthrough.md) — a **Phase 9 codebase audit**,
  preserved as a snapshot of the architecture at that point.
- [`AGENT_REVIEW_2026-06-05.md`](AGENT_REVIEW_2026-06-05.md) — a dated
  agent-behaviour review snapshot.
- [`BACKEND_REVIEW_2026-06-06.md`](BACKEND_REVIEW_2026-06-06.md) — a dated
  backend review snapshot.

## Why archived

The frozen phase journals (185 files, ~3.5 MB) and the dated review
snapshots are history, not roadmap. Moving them under `archive/` keeps
the top of `docs/` focused on the **living** reference docs (SDK/wire
contracts, capability guides) and the **roadmap** surface — the material
that the next roadmap actually builds on. The full narrative arc across
all phases remains in [`../ROADMAP.md`](../ROADMAP.md).
